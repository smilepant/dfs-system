      Drop files to upload

      A check reads every replica of every chunk back from its storage node, compares its SHA-256 with the hash recorded at upload, then reassembles the file from intact replicas and compares it with the file checksum. A passing check confirms the stored content at that moment; it does not guarantee the nodes will stay available. Repair rewrites corrupt or missing replicas from an intact copy, adds replicas where a chunk is below its replication target, and then checks the file again.
